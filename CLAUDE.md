## Работа с файлами в этом проекте
- Путь содержит кириллицу и пробелы → **Bash не может сюда `cd`**. Используй
  PowerShell для команд, Read/Edit/Write — с абсолютным путём.
- ⚠️ **Квадратные скобки в именах файлов и PowerShell.** Роуты Astro называются
  `[category].astro` и `[category]/[slug].astro`. Для PowerShell скобки — это
  подстановочный шаблон, поэтому `Copy-Item "путь\[category].astro"` **молча
  ничего не копирует**. Всегда используй `-LiteralPath` для таких файлов
  (проверено на практике: из-за этого при создании проекта потерялись оба
  файла роутов, и сайт собирался без единой статьи и категории).
- Публикация: `git push` в `main` → GitHub Actions пересобирает сайт (~1–2 мин),
  как только домен подключат и репозиторий будет создан (см. PROJECT.md, п.6).

# Security Rules — ОБЯЗАТЕЛЬНО СОБЛЮДАТЬ

Правила действуют для всего кода проекта (Astro-сайт, скрипты генерации).

## Секреты
- НИКОГДА не хардкодить API-ключи, пароли, токены в код.
- Всегда использовать переменные окружения: `process.env` (Node).
- `.env` всегда в `.gitignore`.
- Секреты для CI — только в GitHub → Settings → Secrets, не в workflow-файлах.

## Зависимости
- Использовать только популярные, проверенные пакеты.
- Периодически `npm audit`; критичные уязвимости устранять.

## Фронтенд
- `textContent` вместо `innerHTML` для пользовательских данных (защита от XSS).
- Никаких `eval()`, `new Function()`, `setTimeout(string)` с внешними данными.
- Эмодзи в UI — только универсальные (до 2010 г.: 🐱🐶🐾💡). Новые (например 🩺, 🪴,
  🥬) рисуются квадратиками на Windows 10 — проверено на практике в «Расти Дома».

## Контент про здоровье животных — особая осторожность
- Это близко к YMYL-теме (здоровье), хоть и не для людей. **Никаких категоричных
  диагнозов** в статьях — только «частые причины» и явная рекомендация обратиться
  к ветеринару при серьёзных/длительных симптомах.
- Не выдумывать дозировки лекарств, схемы лечения — это должен определять ветеринар.

## Как мы пишем (тон сайта)

Читатель приходит из поиска встревоженным: «кошка не ест третий день», «щенок скулит
по ночам». Он часто винит себя. Ему нужен не реферат, а понимание и один посильный шаг.

- **Первый абзац — присоединение, а не лекция.** Назвать состояние читателя нормальным
  и объяснимым (поле `reassurance` во frontmatter).
- **Один шаг вместо пяти.** Поле `tldr` — 2–4 действия на сегодня, не список из десяти.
- **Не обвинять хозяина.** ❌ «вы неправильно кормили» → ✅ «часто получается так, что…».
- **Не ставить диагнозов.** Только «частые причины». Никаких препаратов, дозировок и
  схем лечения — их определяет врач, который видел животное.
- **Блок `redFlags` обязателен** в статьях про симптомы и тревожное поведение. Только
  признаки «нужен осмотр», без диагнозов.
- **Без токсичного позитива.** ❌ «не переживайте, всё будет хорошо» → ✅ «обычно проходит
  за пару дней, но вот когда ждать нельзя…».
- Короткие абзацы, живой язык, ветжаргон — только с расшифровкой.

Эти же правила зашиты в агента `lapki-doma-writer`.
