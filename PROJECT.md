## 1. Цель проекта

Русскоязычный контентный сайт про уход за кошками и собаками — второй источник
пассивного дохода, по тому же проверенному плейбуку, что и «Расти Дома».
Монетизация: реклама Яндекс РСЯ + партнёрки маркетплейсов (Ozon/WB через Такпродам —
тот же аккаунт, что и для растений, нужно только добавить вторую площадку).

## 4. Важные ограничения и вводные

- **Аккаунты и деньги — только владелец.** Домен, GitHub-репозиторий (создаётся
  вручную на github.com — `gh` CLI недоступен в среде), Яндекс-сервисы, почта —
  всё заводит владелец, я веду по шагам.
- **Контент про здоровье животных — не YMYL в чистом виде, но близко.** Никаких
  категоричных диагнозов и схем лечения в статьях — только «частые причины» +
  явная рекомендация к ветеринару при серьёзных симптомах. См. CLAUDE.md.
- **Бюджет** — тот же принцип: 0 ₽ сверх домена (~169 ₽/год на reg.ru).
- **Кириллица в путях ломает Bash** — использовать PowerShell для команд,
  Read/Edit/Write — с абсолютным путём.

## 6. Следующие шаги

1. **Подтвердить и купить домен** `lapki-doma.ru` на reg.ru (или другое имя, если
   передумаем) — делает владелец.
2. **Создать пустой репозиторий на GitHub** (например `Poli6976/lapki-doma`,
   публичный — для бесплатного GitHub Pages) — делает владелец через сайт github.com,
   `gh` CLI недоступен в этой среде. После создания — я подключу и запушу код.
3. **Написать статьи** — движок и шаблон готовы, дело за контентом. Работает агент
   `lapki-doma-writer` (тон и ограничения уже зашиты внутрь), темы подбирает
   `lapki-doma-seo`. Новые поля frontmatter — `reassurance`, `tldr`, `redFlags` —
   образец в статье `kak-priuchit-kotenka-k-lotku.md`.
4. ✅ ~~Дописать оставшиеся файлы~~ — **сделано** (проверено 27.07): `README.md`
   написан, бот в `.github/workflows/generate.yml` переименован в `lapki-doma-bot`,
   User-Agent в `fetch-photos.mjs` указывает на `lapki-doma.ru`, `data/topics.json`
   на месте.
5. **Как только домен и репозиторий готовы** — повторить путь «Расти Дома»:
   CNAME → GitHub Pages → SSL → Яндекс.Вебмастер → Яндекс.Метрика → РСЯ.
   ⚠️ Заранее непонятно, будет ли Cloudflare/pages.dev блокировка — **сразу
   пробовать GitHub Pages**, без промежуточного шага через Cloudflare, раз мы уже
   знаем, что для РФ-аудитории это тупиковый путь.
5. **Написать первую пачку статей** (5–10) под сверхузкие запросы — та же стратегия,
   что дала лучший результат на «Расти Дома»: не «уход за кошкой», а «кошка не ест
   после переезда», не «дрессировка собаки», а «щенок скулит по ночам первую неделю».
6. **Такпродам — вторая площадка**, тот же аккаунт: добавить `lapki-doma.ru`,
   дождаться проверки, найти зоотовары в каталоге.

## 8. Проектирование 27.07.2026 — что и почему сделано

Основа — четыре материала владельца: дизайн-скилл `modern-design-2026`, гайд «10
трендовых стилей 2026», скилл психолога и скилл юриста.

**Дизайн (`src/styles/global.css`, `src/layouts/BaseLayout.astro`)**
- Стиль **Grainy Warm**: тёплый фон `#fbf3ea` с персиковым подсветом вверху,
  плёночное зерно поверх страницы, терракотовый акцент `#d85a2e`.
- Зерно — `opacity: .12` вместо `.35` из гайда: плотное зерно мешает читать длинные
  статьи.
- Заголовки — **Vollkorn**. Fraunces из оригинального стиля и прежний DM Serif
  Display **не имеют кириллицы**, русские заголовки падали на Georgia.
- `--text-soft` затемнён до `#786052`: вариант из гайда давал контраст 4.09 — ниже
  нормы WCAG AA. Стало 5.32.
- Шкала отступов `--sp-1…--sp-9` с большими скачками между секциями.
- Движение построено на **переходах, а не на keyframes с fill-mode**: конечный вид
  задаёт класс, поэтому незапустившаяся анимация не может «съесть» контент.
  Плюс страховочные таймеры, которые показывают всё принудительно.

**Главная (`src/pages/index.astro`)**
- Вход через вопрос «Что случилось у питомца?» и чипы-ситуации. Чип сам находит
  статью по ключевым словам, а пока её нет — ведёт на категорию.
- Бенто-сетка категорий с намеренно неравными ячейками (7 и 5 колонок из 12).
- Блок «Как мы пишем» — доверие для читателя и E-E-A-T для поиска.

**Статья (`src/layouts/ArticleLayout.astro`, новые компоненты)**
- `CalmIntro` — валидация + «что сделать в первую очередь» (принцип психолога
  «сначала присоединение, потом техника»).
- `VetAlert` — красные флаги. Полоса слева, а не красная заливка: напуганному
  человеку красный экран делает хуже.
- `VetDisclaimer` — справочный характер материалов.
- Партнёрское раскрытие **перенесено** из шапки статьи к блоку товаров: раньше
  первое, что видел встревоженный человек, — «мы получаем комиссию».
- Новые поля схемы: `reassurance`, `tldr`, `redFlags` (все опциональные).

**Юридический слой** — политика под 152-ФЗ, cookie-полоса, маркировка рекламы по
ст. 18.1 ФЗ «О рекламе» (поля `erid` и `advertiser` в товарах), сведения о владельце.
⚠️ Это заготовка, а не юридическое заключение: режим маркировки партнёрских ссылок
владельцу стоит подтвердить у практикующего юриста до подключения партнёрок.
