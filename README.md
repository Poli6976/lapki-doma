# 🐾 «Лапки Дома» — сайт про уход за домашними питомцами

Русскоязычный контентный сайт на **Astro** под **российскую монетизацию**. Второй сайт
в портфеле, построен на том же движке, что и «Расти Дома» (сайт про растения).

> ⚠️ **Актуальный статус проекта — в `PROJECT.md`**, не здесь. Этот файл — только
> техническая справка (как запустить, как устроен код). Даты, решения и следующие
> шаги быстро устаревают — держим их в одном месте.

> ⚠️ **Почему русский, а не английский.** Google AdSense и Amazon не выплачивают
> деньги на счета в РФ. Монетизация — **Яндекс РСЯ** + партнёрки российских
> маркетплейсов (Ozon, Wildberries) через Такпродам.

> ⚠️ **Хостинг — сразу GitHub Pages**, не Cloudflare Pages. На «Расти Дома» проверено:
> Cloudflare блокируется в РФ по IP, свой домен это не спасает. GitHub Pages — работает.

---

## Как запустить у себя

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # финальная сборка в dist/
```

## Как добавлять статьи

Руками, без интернета:

```bash
npm run new -- "Почему кошка не ест после переезда" zdorovie-i-povedenie
```

Категории: `koshki`, `sobaki`, `zdorovie-i-povedenie`, `sovety`.

## Обложки статей

Только настоящие фото: `node scripts/fetch-photos.mjs` — тянет снимки с Wikimedia
Commons (проверяемая лицензия, автор записывается во frontmatter). Нужно сначала
вписать статью в `PHOTO_QUERIES` внутри скрипта.

Дополнительно `--sets` качает галереи внутрь статей и ленты фото на страницы
категорий.

⚠️ **Каждое фото смотреть глазами перед публикацией** — автопоиск ошибается грубо
(присылал музейные статуэтки, схемы и кадры, недопустимые на сайте о питомцах).

Нарисованных SVG-заглушек больше нет: владелец их отверг 27.07.2026, скрипт
`generate-covers.mjs` удалён. Если фото под тему не нашлось — статья пока
остаётся без обложки, это лучше, чем чужеродный рисунок.
